# Wait, what?

Use when a message did not land or the user asks what you mean.

Re-pitch the last idea, not the whole session:

1. State the goal in one sentence.
2. Define every unfamiliar term before using it.
3. Explain why the step matters and where it fits in the system.
4. Give one small example or one concrete next action.

Use plain words and short sentences. Do not repeat the original wording or add
new jargon. If the user is still lost, ask which sentence stopped making sense.

Say that you are using this skill and why before you begin.
