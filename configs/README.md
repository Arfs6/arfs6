# Configs

My configurations for the tools I use. The repository-level
[`setup.sh`](../setup.sh) links these into the correct home locations using
[`dotfiles.manifest`](../dotfiles.manifest).

## Contents

- [Neovim](./neovim): Neovim configuration, snippets, and filetype settings.
- [oh-my-posh](./ohmyposh): Prompt theme.
- [opencode](./opencode): Agents, commands, skills, TUI settings, and notifications.
- [shells](./shells): bash, zsh, aliases, and environment variables.
- [tmux](./tmux): tmux configuration.
